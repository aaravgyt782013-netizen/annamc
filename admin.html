Before going live

Important operational limits.

  • Store and site settings need a working database.
  • Game modes configure website information, not Minecraft server processes or Velocity routing.
  • Payment verification and automatic rank delivery require separate integrations.
  • Changes are reported only after the API confirms the save.

Example: {"theme":{"primary":"#e6c34f"},"textOverrides":{"h1":"New heading"},"hideSelectors":[".old-banner"]}. Overrides replace text content; do not use untrusted HTML.
